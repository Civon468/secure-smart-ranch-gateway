Timestamps and logging 

    python has a library modules called datetime and logging

    EX:
        from datetime import datetime

        Timestamps =datetime.now().isoformat(Timespec="seconds")

    A Timestamp help establish when a reading was processed. the example uses local system time, so it is not guaranteed to be synchronized or accurate.

    Logging 

    EX:
        import logging

        logging.basicConfig(
            filename="could be named any file",
            level=logging.INFO,
            format="%(asctime)s - %(levelname)s - %(message)s"
        )
    This configures Python's logging system.

    filename: sends log records to "could be named any file".

    level=logging.INFO: allows informational messages and more severe messages, such as warnings.

    format: specifies the timestamp, severity level, and message layout.

    The program can then record events:

        if status == "WARNING":
            logging.warning(
                f"Sensor {sensor_id}: temperature={temperature}"
            )
        else:
            logging.info(
                f"Sensor {sensor_id}: temperature={temperature}"
            )

    The f before the string allows variable values to be inserted into the message.
